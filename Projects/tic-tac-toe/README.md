# Tic-Tac-Toe Game

A simple command-line Tic-Tac-Toe game written in Python.

## How to Play

1. Run the Python script in your terminal.
2. The game is played on a 3x3 grid, represented by numbers from 1 to 9.
3. Two players take turns. Player 1 is `X` and Player 2 is `O`.
4. During your turn, enter the number corresponding to the position where you want to place your mark.
5. The first player to get 3 of their marks in a row (up, down, across, or diagonally) wins.
6. If all 9 squares are filled and no player has 3 marks in a row, the game is a draw.
7. After the game ends, you will be asked if you want to play again (`Y` for Yes, `N` for No).

## Running the Game

Open your terminal or command prompt and run the following command:

```bash
python tictactoe.py
```
